# Optional cloud diagnosis trial

Local diagnosis stays unlimited. The optional 30-day Team trial adds up to 50 cloud diagnoses a day and saved incident history. No card or automatic subscription. When the trial ends, free local diagnosis continues. Paid team features require a subscription you choose.

1. Enter your work email. We email you a code.
2. Paste the code into VS Code. Your account and trial are set up and this editor is connected, without opening a browser. No API-key copying and no automatic log upload.

Established company domains can activate automatically after email and domain checks, regardless of mail provider. If a domain cannot be verified automatically, email support@denpex.com for review; once it is approved, run **Denpex: Finish Trial with Emailed Code** again.

[Start the free 30-day Team trial](command:denpex.startTrial)

Already have the code? [Finish Trial with Emailed Code](command:denpex.finishTrial).

Already have an eligible account? [Connect Account](command:denpex.connectAccount).

Manual key setup is an advanced option for self-hosted deployments.
